# ICLR experiment workspace

Start a GPU session in [handoff/](handoff/), then read [GPU_HANDOFF.md](handoff/GPU_HANDOFF.md), [EXPERIMENTS_REQUIRED.md](handoff/EXPERIMENTS_REQUIRED.md), and [REVIEW_PANEL_RESPONSE.md](handoff/REVIEW_PANEL_RESPONSE.md). The directory contains ordinary Git-tracked files, not an Overleaf submodule. Pulling this research repository supplies the context, paper snapshot, archived data and CPU checks without Overleaf credentials.

This project studies leading/tail singular components and regularization. Adapters are experimental instruments, not candidates in a best-adapter claim. The full nine-page-main-text paper is in [handoff/neurips_2026.tex](handoff/neurips_2026.tex); original GLUE values and the single MRPC accuracy column are preserved.

The expanded training runner is still to be implemented and validated in a dedicated checkout. Before launching, obtain assigned GPU IDs, a compute budget and persistent storage. Do not modify another agent's checkout, outputs or jobs.
