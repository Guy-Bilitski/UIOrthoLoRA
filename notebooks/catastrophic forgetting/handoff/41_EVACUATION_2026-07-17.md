### Restoring a DeepSeek raw adapter
Each adapter (base `deepseek-ai/DeepSeek-V4-Flash`, r16/α32, MLA-attn targets) was tarred and
`split -b 95M`'d because GitHub rejects files >100MB and no git-lfs was available. To restore:
```bash
cd "notebooks/catastrophic forgetting/results/ds_adapters_evac"
cat dsv4_<method>_r16_lr<lr>_s<seed>.tar.part-* | tar xf -   # -> full adapter dir
```
See `results/ds_adapters_evac/README.md`. To list what actually landed:
```bash
git ls-tree -r --name-only origin/ortho_new | grep -oP 'ds_adapters_evac/\K[^/]+(?=\.tar)' | sort -u
```
Push order was diversity-first (all 7 methods @ seed42, then s43, then s44), so partial coverage
still spans every method. If a `.tar.part-*` set is incomplete for one run, that run's upload was
cut off mid-transfer — its weights are lost, but its geometry + adapt score are still in the files above.
