All figures are regenerated by self-contained scripts under `paper/writing/`.
Each script reads the data **live** (no hardcoded numbers except published-paper
anchors, which cite their source), writes a vector **PDF** (for the paper) and a
**PNG** (preview) into this directory, and prints the key statistic it drew.

Shared cosmetics live in `paper/writing/figstyle.py`: the colorblind-safe
light-mode categorical palette (the data-viz skill's pre-validated reference
palette, worst adjacent CVD ΔE 24.2 ≥ 12 target), a fixed **method → colour +
redundant marker** map (identity is never colour-alone), and the print rcParams.
Colour follows the entity, so a method is the same colour in every figure.

Regenerate everything:

```bash
cd "notebooks/catastrophic forgetting/paper/writing"
for f in fig_magnitude_law fig_geometry_4panel fig_efficiency \
         fig_ce_vs_magnitude fig_cross_literature; do
  /home/guy/UIOrthoLoRA/.venv/bin/python $f.py
done
```

## Provenance of the numbers

- Figs 1–4 recompute every plotted value from the campaign registries / result
  JSONs at run time. The magnitude axis is **F_Δ** (CLoRA Eq. 3 effective update
  magnitude, field `fdelta` / `headline.fdelta`), per `data/key_numbers.md §0`.
  CorDA is excluded from the CS law (Fig 1) per `key_numbers.md §8`.
- Fig 5 is the **only** figure that hardcodes numbers; every one is a published
  table value cited in-code:
  - CLoRA (Kim et al., 2025) Table 4 — F_Δ vs BBH (reference/full-FT row excluded).
  - MiLoRA (Wang et al., 2024) Tables 7 (‖ΔW‖) & 8 (CE-to-base, Kalajdzievski 2024).
  - LoRA-Null (Table 4b) — capacity→retention note (qualitative; no scatter-able
    points published).
